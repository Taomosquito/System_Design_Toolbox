# One Button Speedrun Phase Switch
## Core Principle
* This will be a single button that starts a timer.
    * The second press will start the second timer in a loop until an exit button is pressed.
        * The program will prompt phase name changes sequentially after exit is pressed and the cumulative total is established.
        * The program will prompt for overall run name as well.
* BONUS:
    * will update to allow reaccessing previous runs with all associated phases.
